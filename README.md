# Gift Planner

A simple, private web app for planning birthday and Christmas gifts. Works on iPhone and Android, installs to the Home Screen, and works offline.

## Features
- Upcoming birthdays with countdowns and gift-status reminders
- Gift ideas per person, with prices in £, and a bought tick
- Christmas list with budget totals, per-person subtotals and a "sorted" mark
- Overall Christmas budget plus per-person Christmas and birthday budgets
- Edit any idea later (update the real price), and hide a person's gifts when showing someone the app
- Add birthday or Christmas reminders to Apple or Google Calendar
- Add people manually, from a .vcf contacts file, or via an iOS Shortcut
- Backup and restore

## Privacy
There is no server and no account. Everything is stored in your own browser on your own device, and nothing is uploaded. Use **People > Backup & restore** to keep a copy.

## Host it (GitHub Pages)
1. Put all files in a repository.
2. Settings > Pages > deploy from the main branch.
3. Open the https address on your phone, then Share > Add to Home Screen (iPhone) or Install app (Android).

Open it from the Home Screen icon afterwards: on iPhone, the Home Screen app stores its data separately from Safari.
